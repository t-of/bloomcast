# BLOOMCAST — 雲で日差しと雨を配って育てる

空の雲を指で動かして太陽を隠し、長押しで雨を降らせて、画面の下の植物をできるだけ早く実らせる。ほしい日差しと水は朝・昼・夕と育ち具合で変わるので、動く太陽を追いかけて雲を配り直す。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/bloomcast/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. **雲を指で動かす**と、太陽にかかったぶんだけ日差しが弱くなる。左のゲージ（日差し）の**緑の帯**に合わせる。
2. **雲を押したまま 0.25 秒止めると雨**。押している間だけ降り、降らせながら動かせる。植物の真上で降らせると土がしめる。右のゲージ（水）の緑の帯に合わせる。
3. 両方が帯に入っているほど早く育つ。ほしい量は時間帯（朝・昼・夕・夜）と育ち具合（芽 → 葉 → つぼみ → 花）で変わる。実がなるまでのタイムを競う。

- 指 2 本で別々の雲を扱える（1 つで太陽を隠し、1 つで水やり）。
- 雨を降らせると雲は水を使って小さくなり、降らせていない間に少しずつ戻る。
- 帯から大きく外れていると元気が減り、0 になると枯れる。5 分でクリアできなければ時間切れ。
- 夜は日差しを見ず、水だけ。育ちは半分の速さ。
- 植物は 3 種: トマト（やさしい・雲 2 つ・風なし）、イチゴ（ふつう・雲 2 つ・弱い風）、サボテン（むずかしい・雲 3 つ・強い風と突風）。
- ★★★ は目安のタイムの 1.15 倍以内、★★ は 1.5 倍以内。
- ポーズは左上のボタン（PC は Esc / P）。画面が裏に回ると止まる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node tools/test.js            # 決まりの自己チェック
node tools/sim.js             # 釣り合いの測定（植物 3 × ボット 8 × 200 回。十数秒）
node tools/sim.js --plant tomato --bot greedy --runs 200
```

| ファイル | 中身 |
|---|---|
| `js/model.js` | 決まり（太陽・雲・日差し・雨・土の水・育ち・元気・風）。DOM に触らず、ブラウザと node で同じコードを動かす。1/60 秒の固定刻み。数はすべて `CONFIG` |
| `main.js` | 画面（描く・触る・鳴らす・保存）。画面の速さに関係なく固定刻みでモデルを進める |
| `tools/sim.js` | ボットで打たせて釣り合いを測る |
| `tools/test.js` | 自己チェック |

保存するもの（localStorage）: `bloomcast.settings`（`{ v: 1, sound, coached }`）、`bloomcast.best`（`{ v: 1, plants: { tomato: { ms, stars, splits } | null, … } }`）。読めない・知らない項目は捨て、足りない項目ははじめの値で埋める。

### 釣り合い（2026-09-25）

ボット（`tools/sim.js`）:

| ボット | 打ち方 |
|---|---|
| greedy | 上手。指 2 本、1 秒に 2.0 動かせる。水が帯の下 3 割を切ったら水の多い雲を植物の上で降らせ、残りの雲で太陽を「ほしい日差し ÷ 日の強さ」だけ隠す |
| human | greedy に 0.4 秒の遅れ、位置のぶれ ±0.02、速さ 1.2、指 1 本（持ち替え 0.3 秒） |
| random | 1.5 秒ごとに雲を 1 つでたらめな所へ。25% でそのあと 1.5 秒降らせる |
| idle / cover / rain | 何もしない / 雲を全部いつも太陽に重ねる / 雲 1 つをいつも植物の上で降らせる |
| no-time / no-stage | greedy だが、いつも昼の帯を見る / いつも芽の帯を見る |

合格の目安（仕様）: greedy の中央値がトマト 65〜85 秒・イチゴ 80〜110 秒・サボテン 90〜130 秒。human は greedy の 1.4 倍以内で枯れ 5% 未満（サボテンは 1.6 倍・15%）。random はクリア 20% 未満。idle・cover・rain はクリア 0%。no-time・no-stage は greedy の 1.2 倍以上遅い（枯れたものは無限に遅いとして中央値を取る）。

**直した数値**

| 何を | 前 | 後 | 理由 |
|---|---|---|---|
| 日差しの帯を日の強さより上に置かない（`bandL = min(帯, 日の強さ)`） | なし | あり | 日の出・日の入りのころは雲で日差しを足せないのに「大きく外れ」になり、毎朝・毎夕、打つ手なく元気が減っていた（human のサボテンが 90% 枯れた原因） |
| トマトの朝・夕の日差し | 0.40/0.40, 0.50/0.50, 0.55/0.50, 0.60/0.55 | 0.35/0.35, 0.45/0.45, 0.50/0.45, 0.55/0.50 | 時間帯で打ち方を変える意味を出す（no-time 1.10 → 1.22 倍） |
| イチゴの育つ速さ G | 1.4 | 1.2 | 1 行目の直しのあと greedy が 77.7 秒になり、目安より速かった |
| イチゴの朝・夕の日差し | 0.40/0.35, 0.50/0.45, 0.60/0.50, 0.65/0.50 | 0.50/0.45, 0.60/0.55, 0.65/0.60, 0.70/0.60 | 「昼の強い日差しが苦手」をはっきりさせる（no-time 1.19 → 1.34 倍） |
| イチゴの水（芽・葉・つぼみ・花） | 0.60, 0.65, 0.70, 0.60 | 0.55, 0.65, 0.75, 0.60 | 段階で水を変える意味を出す（no-stage 1.18 → 1.63 倍） |
| サボテンの育つ速さ G | 1.4 | 1.0 | 1 行目の直しのあと greedy が 78.6 秒になり、目安より速かった |
| ★ の目安（greedy の中央値） | — | トマト 79 秒・イチゴ 90 秒・サボテン 109 秒 | |

**直す前**（仕様の最初の値、各 200 回。タイムは秒）

| ボット | トマト | イチゴ | サボテン |
|---|---|---|---|
| greedy | 88.3 ✗ | 85.3 | 98.9 |
| human | 102.4（1.16 倍・枯れ 0%） | 110.9（1.30 倍・枯れ 0%） | クリア 10%・枯れ 90% ✗ |
| random | クリア 0% | クリア 0% | クリア 0% |
| idle / cover / rain | クリア 0% | クリア 0% | クリア 0% |
| no-time | 97.3（1.10 倍）✗ | 101.6（1.19 倍）✗ | 129.9（1.31 倍） |
| no-stage | 143.0（1.62 倍） | 101.0（1.18 倍）✗ | 159.9（1.62 倍） |

**直した後**（各 200 回）

| ボット | トマト | イチゴ | サボテン |
|---|---|---|---|
| greedy | 78.6 | 89.7 | 108.7 |
| human | 91.8（1.17 倍・枯れ 0%） | 108.0（1.20 倍・枯れ 0%） | 170.2（1.57 倍・枯れ 5%） |
| random | クリア 0% | クリア 0% | クリア 0% |
| idle / cover / rain | クリア 0% | クリア 0% | クリア 0% |
| no-time | 95.8（1.22 倍） | 120.3（1.34 倍） | 139.2（1.28 倍） |
| no-stage | 109.5（1.39 倍） | 146.0（1.63 倍） | 166.9（1.54 倍） |

トマトは風がないので、greedy・no-time・no-stage は種によらず毎回同じタイムになる。ぎりぎりなのはトマトの no-time（1.22 倍）とサボテンの human（1.57 倍）。数値を動かしたら `node tools/sim.js` で確かめ直す。
